# SALES ANALYSIS DASHBOARD

- This is my Power BI project based on the sample superstore dataset.
- it helps me analyze sales,profit,product categories,and customer segments.

  # OBJECTIVE: -
 - Analyze sales and profit.
 - compare product categories.
 - Understand customer segment performance.
 - Track sales trend over time.

   
   # TOOLS USED: -

   TOOL                              PURPOSE
   POWER BI                          DASHBOARD CREATION
   POWER QUERY                       DATA CLEANING
   DAX MEASURES                      CALCULATIONS
   EXCEL                             DATASET

   # DAX MEASURES: -
   TOTAL SALES
   TOTAL PROFIT
   AVERAGE SALES
   AVERAGE PROFIT
   MAXIMUM SALES AND PROFIT
   MINIMUM SALES AND PROFIT
   MAXIMUM AND MINIMUM QUANTITY
   TOTAL /COUNT OF ORDERS/PRODUCT
   

   # PROJECT STEPS: -
   1. Imported data from excel.
   2. Cleaned data using Power Query
   3. Prepare Data model
   4. Created DAX Measures.
   5. Designed KPI Cards,Charts,and Slicers.
   6. Tested the dashboard.
  
   
  
   # DASHBOARD FEATURES: -

   1. KPI CARDS
   2. SALES AND PROFIT ANALYSIS
   3. CATEGORY-WISE SALES
   4. CUSTOMER SEGMENT ANALYSIS
   5. MONTHLYSALES TRENDS
   6. INTERACTIVE SLICERS
  
   # KEY INSIGHTS: -

   The Dashboard helps explore sales pattern, compare Categories and understand profit performance. Actual insights are based on the dashboard results.
